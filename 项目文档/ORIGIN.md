# Source lineage

BranchLoom is a renamed and restructured derivative. Its functional baseline is
`imaflyfish/deflat64` at commit `ef59221440234bee50d3061ce23fc3f8749afbbc`.
The v0.2.0 release history separately records the original `unflatten64`
implementation by DumpA1n. The 0.2.1 package metadata names dhtfish98
as the current maintainer; earlier bitfish886 and dhtfish988 attribution remains
part of the historical and MIT copyright record. Maintenance metadata does not
transfer or erase upstream rights. The original MIT notices remain in LICENSE,
and unvalidated behavior remains subject to the documented limits.
